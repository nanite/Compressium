# Compressium

**Adding compressed blocks to the game since 2019**

Got a double chest full of cobblestone? A mountain of sand taking up half your storage? Compressium solves that.

Compress any supported block into a denser, more compact form — up to 9 levels deep. Each compression level represents 9x the material of the last, so a single 9x compressed cobblestone block holds the equivalent of over 387 million cobblestone. Store more, haul less, lag less.

Compressed blocks are fully survival-friendly. Craft them in a 3x3 grid using the previous tier, and reverse the process at any time to get your materials back.

## Compression Levels

Each block supports 9 tiers of compression:

| Tier | Equivalent Blocks |
|------|-------------------|
| 1x   | 9                 |
| 2x   | 81                |
| 3x   | 729               |
| 4x   | 6,561             |
| 5x   | 59,049            |
| 6x   | 531,441           |
| 7x   | 4,782,969         |
| 8x   | 43,046,721        |
| 9x   | 387,420,489       |
